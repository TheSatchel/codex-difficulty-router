本技能通过 prompt 约束原生 subagent 的使用，Codex 优先，兼容 Claude Code。主对话保持当前模型，默认负责理解需求、判断难度、分配任务、验收和汇总；有足够任务信息且满足下列限制时，把实际执行优先交给子代理。委派不扩大用户对文件写入、外部操作、费用或权限的授权。

## 先检查路由并说明状态

难度由当前主对话模型判断，不另起一个评估模型。Artificial Analysis 分数用于比较候选模型，不是任务本身的客观难度分数，不把主模型的估计说成已经校准的测量结果。已被委派的子代理只完成父代理分配的工作，不重新启动这套调度流程。

首次采用本规则、主模式变化或委派受阻时，用一句话说明可信会话信息确认的主模型／推理档、路由动作与原因；实际模式未知就如实说未知。后续状态不变时不重复播报，不每轮输出档位建议。

尚未提供具体任务时，明确说“已检查路由，等待具体题目，尚未派发”，再澄清所需输入；这时无需提前查榜、估计能力下限或创建空子代理。已有实际任务时，按下文检查准入和上限再执行。评分缺失、上限未知、超出上限或工具不可用时，明确指出阻塞项，不静默跳过检查或把主对话直接回答称为已委派。

## 先确定任务和主对话上限

结合当前需求、项目证据、未知项和验证要求估计任务的能力下限与可能需要的上限，区分难度和紧急程度。续做保留原任务范围；不要把“继续”当成简单新任务，也不要仅凭仓库大小升档。用户只说“有个最难的问题，准备一下”而尚未给出题目时，先等待实际问题，不空派子代理。

从可信的当前会话信息确认主对话实际模型、推理档和速度，不用全局默认配置冒充当前模式。每个子代理同时受用户明确的预算上限和主对话实际模式约束：

- 精确型号／推理档对应的实测 Intelligence Index 不高于主对话。
- 推理档不高于主对话；只比较宿主明确支持的档位，不猜测跨宿主名称的对应关系。
- 速度不高于主对话，按 `normal / fast / ultrafast` 比较；推理档 `ultra` 是另一维度。

主模式或评分证据不足时不猜上限，不新建无法证明合规的子代理；也不为绕过上限提高主模式。若主模式的精确实测评分缺失，明确报告“主模式评分缺失，无法验证子代理上限，本轮未派发”；不能借用相近版本、其他推理档或估算分数。小模型主对话不能把超出其能力上限的难题交给更强子模型。若任务在当前上限内无法完成，说明限制，保留未完成状态。

## 选择足够的子模型并执行

只从宿主实际提供的模型和推理档中选择，并使用 Artificial Analysis 的实测 Intelligence Index 对照精确型号与推理档。缺失、null、估算、过期或名称不明确的评分不能授权新调用；不借用 Max 的分数给 Ultra，不试调用未知模型。继承主模型仍是一次新的子代理调用，不能绕过评分准入。

在达到任务能力下限且不超过上限的候选中比较成本与速度，优先足够的小模型。紧急任务衡量提速收益与额外费用，不默认使用强模型 ultrafast；把子代理启动、上下文传递、复核和失败重试也计入开销。网页 API 价格、ChatGPT credits 和套餐额度不能混成同一计费单位，未知价格或吞吐率保留未知，不凭空替用户设置预算。

**本规则请求在适合的执行任务中使用原生 subagent，不以主对话处于 Ultra 为前提。** 使用宿主实际暴露的创建、继续、等待和关闭工具；需要不同模型或推理档时显式传入支持的参数，未指定时按宿主的继承规则处理，不把默认继承称为已经按难度选模。

当前 Codex 子代理接口没有单独速度参数，服务档跟随主会话；按宿主明确提供的继承语义约束速度，不编造 `speed` 或 `service_tier` 参数。其他宿主只按其真实接口处理；既不能设置又没有明确继承语义时，说明速度上限无法验证，不盲目派发。

每个子任务应有明确输入、交付物、验收条件和写入范围，并携带主对话上限及必要证据。独立任务可以并行，共享 checkout 的冲突写入串行；子代理不得递归委派。主对话不重复子代理已经负责的工作，返回后检查交付物与必要验证，整合结果，再关闭已完成的子代理。创建成功不等于任务完成，最终只报告宿主确认过的执行状态和结果。

极短问答、强耦合决策和必须立即解决的关键阻塞可以留在主对话，避免委派开销大于收益。没有合规候选、原生 subagent 不可用或调用失败时，明确原因；不偷偷调用未评分或越界模型，主对话只能在现有授权和能力内继续。不要把未委派、未完成或验证失败说成成功。

## 加载、数据和系统边界

Skill 通过宿主的正常发现机制按需加载；需要默认进入路由检查时，使用正常个人指令中的[入口规则](../../prompts/codex-entry.md)，由它要求先读取当前已启用技能的正文。入口只在技能出现在当前可用列表时生效，不硬编码版本目录，也不在禁用或卸载后寻找历史副本。这是文字指令，不是 hook 或执行器，不能把指令存在等同于模型已经执行。

主对话模型不会因为本规则自动切换；普通持久化聊天不再作为自动拆分目标，不向其他聊天发送隐藏消息或用额外 Codex 进程模拟子代理。Claude Code 仅使用其已有 subagent 能力，不虚构 Codex 专属接口。

优先使用已有有效缓存；网络可用时读取公开榜单。缓存应覆盖所有公开厂商、模型、推理档、退役及未评分条目，选择时再与宿主目录取交集。可选数据工具为 [router-data.mjs](../../bin/router-data.mjs)，仅处理公开榜单与本地 JSON，必须显式接收缓存目录，不在插件加载时运行；不要重建用户已清理的全局数据目录。无需该工具时使用宿主现有网页读取能力。

**为路由创建 LaunchAgent、daemon、后台服务、MCP server、用户级 hook，修改 `CODEX_*` 环境变量、全局配置、App 文件或 app-server 连接，均不属于本技能。不得执行这些操作或运行历史版本的安装器。** 仅通过 prompt 引导宿主现有工具，不恢复旧版桌面接入。
